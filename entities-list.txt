# NOTE ON THE "vehicle_" PREFIX (Fleet Sensor Aliases):
# All entity_ids below starting with sensor.vehicle_* / binary_sensor.vehicle_*
# are NOT raw Tesla Fleet entities. They are dashboard-stability aliases defined
# in configuration.yaml that dynamically read from sensor.<car>_* / binary_
# sensor.<car>_* using input_text.tesla_car_name, so dashboards/automations
# never need editing if the vehicle is renamed. "vehicle_" is a deliberately
# reserved, fixed prefix — DO NOT ever name your actual vehicle "vehicle" in
# input_text.tesla_car_name, or these aliases will read their own state and
# get stuck on "unknown" (see automation "tesla_reserved_car_name_guard" in
# packages/tesla/automations.yaml, which warns if this happens). Any car name
# is otherwise safe, including "tesla", single letters, or numbers ("x", "0", "42").
# ============================================================

# 1. This vehicle uses the official Tesla Fleet integration.
# 2. Entity prefix for this car = "tesla_"
# 3. No Powerwall / Solar / Energy Site entities are currently present (vehicle only).
# 4. Many useful derived statistics already exist as Templates (especially cost & efficiency tracking).
# 5. When adding NEW helpers/templates:
#    - Add them to the "CUSTOM TEMPLATES..." section above.
#    - Give them clear friendly_names starting with "Tesla ..." or "Tesla ...".
#    - Set proper device_class, state_class, unit_of_measurement, and unique_id.

#    - Use sensor.vehicle_battery_level directly (no template wrapper needed)
#    - sensor.tesla_remaining_range (template combining usable_battery_level + ideal_battery_range)
#    - input_number.tesla_target_charge_limit (user-friendly slider for charge limit)
#    - binary_sensor.tesla_is_home (based on device_tracker + zone)
#    - script.tesla_precondition_departure
#    - [DONE] Smart charging: input_boolean.tesla_enable_smart_charging +
#      input_datetime.tesla_smart_charge_window_start/_end, consumed by
#      automations tesla_smart_charge_start / tesla_smart_charge_stop in
#      packages/tesla/automations.yaml (at most 1 start + 1 stop per day,
#      no flapping; syncs the vehicle's own charge limit as a safety net).
